# StaySphere 🏠

StaySphere is a property rental and booking web application that allows users to explore properties, view listings, and manage bookings.

## 🚀 Features

- 🏠 Property listings
- 🔍 Search and explore properties
- 🔐 User authentication
- 📅 Property booking
- ❤️ Wishlist
- ⭐ Reviews and ratings
- 📋 Reservation management
- 📍 Property details and availability

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## 📌 Project Overview

StaySphere provides a simple platform for users to discover rental properties and manage their reservations. The backend is built with Node.js and Express.js, while MongoDB is used for storing application data.
